# Me

Personal portfolio for **Ajith M T** — Creative Full Stack Developer.

Architected with high-fidelity editorial design, warm-cream aesthetic, interactive 3D physics badge, voice-guided introduction, and responsive components.

## Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack, React 19, TypeScript)
- **Styling:** Vanilla CSS with custom design tokens, modern typography, and glassmorphism
- **Audio & Animations:** Pre-rendered neural voice synthesis, 3D CSS perspective card tilt, and keyframe visualizers
- **Icons:** [lucide-react](https://lucide.dev/)

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## Production Build & Deployment

To build for production (Vercel-ready):
```bash
npm run build
npm run start
```

## Features
- **Editorial Hero Section:** Centered 3D animated character, interactive talking intro button with animated soundwaves, clean border padding, and oversized background typography.
- **Hanging Lanyard ID Badge:** 3D interactive physics tilt with mouse movement and flip-to-inspect credentials card back.
- **Interactive Skills Arsenal:** Real-time search filter and project mapping across 23+ skills.
- **Career Trajectory & Metrics:** Interactive company switcher with achievement milestones and tech tags.
- **Featured Projects:** Deep-dive architectural highlight drawers and verified live/code links.
- **One-Click Contact Hub:** Instant clipboard copy, live availability radar, and validated direct messaging form.
- **Clean URLs:** Smooth section scrolling with zero hash pollution in the browser address bar.
